关键洞察：三条路线的演进关系

路线1 → 路线3 无需经过路线2
路线1的"成品方案" → 拆解成最小颗粒度 → 路线3的"POI特征库"
意思是：你现在GitHub Pages那12条方案，其实已经是路线3要用的POI数据的"半成品"。
拆成最小单元后，再用规则重新组合，就能生成比12条多得多的方案组合。
例如：「潮阳站3小时花500」这条方案 → 拆成 潮阳站(坐标) + 东山公园(POI) + 麦当劳(POI) + 步行10分钟(路线) → 可组合出"铜盂2小时"方案
